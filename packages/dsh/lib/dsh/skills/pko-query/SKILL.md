# 知识库问答

## 步骤

1. **检索**：`pko_query`，query 直接用用户的原话（不要自己改写成一堆关键词）。
2. **读原文**：候选里最像的那 1–2 页用 `pko_read` 读全文，不要只凭摘要回答。
3. **组织回答**：结论 + 来源路径 + 可信度（页面有 `confidence` 就带上）。
4. **诚实兜底**：库里没有就直接说「vault 里没有这部分内容」，并建议是否要摄取外部资料。

## 规则

- 不把推断说成库里的结论
- 发现页面互相矛盾时，把矛盾点列出来等用户判断，不要自己选一个
- 回答后可以问一句「要不要把这次结论存进库」
