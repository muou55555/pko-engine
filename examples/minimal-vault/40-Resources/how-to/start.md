# 从这里开始

## 1. 让它认识这个库

在库目录里打开 DSH 会话。第一次会话会自动把 8 个技能投放到 `.dsh/skills/`。

## 2. 试试这三个命令

- `/pko-daily` — 恢复上下文、列今日待办
- `/pko-query 我记过什么` — 查自己的积累
- `/pko-save` — 把当前对话里有价值的内容存下来

## 3. 让它更好地认识你

编辑 `50-Wiki/hot.md`，写上你最近在做什么；编辑 `brain/north-star.md`（可选），写上当前目标。
这两处会在每次会话开始时被注入，是"模型记得你"的关键。

## 为什么重要

知识库不是用来"存"的，是用来"用"的。每次查资料先问它，积累才复利。
